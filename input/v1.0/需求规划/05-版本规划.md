## 〇、版本策略一句话

> 分 **3 个版本**推进：**V1.0 先跑通核心闭环 + 立安全/合规基座 → V1.1 提门口现场核验放行效率 → V1.2 增被访人与访客的协同便捷**。每版走完「阶段三需求梳理闭环 → 阶段四 PRD 封版」后**独立封版**，成为该版开发唯一输入。

## 一、全部规划版本切片（边界骨架）

| 版本 | 定位 | 边界骨架（模块范围 / 闭环目标） | 依赖 | 说明 |
|------|------|------------------------------|------|------|
| **V1.0** | 首版 · 核心闭环 + 安全基座 | **打通全流程闭环**：PT 统一门户 + AP 访客预约 + AT 被访人审核 + GV 门卫核验放行 + VS 访客门户（手机端）+ LG 访客台账 + AN 统计分析 + OR 组织权限 + BD 主数据 + NT 通知（站内）+ SM 系统管理。**内含增补**：**G1 在校（实时）清单**（安全核心视图）、**G11 个人信息保护基础**（授权告知 / 留存期限 / 到期脱敏） | 无（首版） | 「预约 → 审核 → 核验 → 放行 → 离校 → 留痕」全流程可跑通，并具备**在校实时清单**与**隐私合规基础** |
| **V1.1** | 增强 · 现场效率 | 在 V1.0 的 **GV 门卫核验放行** 与 **BD 主数据** 上增强现场能力：**G2 证件识别** · **G3 现场人像采集** · **G5 超时催离 + 批量核销** · **G9 访客证 / 临时通行卡** · **G10 车牌识别 · 道闸联动**（开关预留） | V1.0 | 门口核验放行**更快更准、减少滞留**；G10 以**开关预留**形式交付，有设备再启用（可配，§3.25） |
| **V1.2** | 扩展 · 协同便捷 | 在 V1.0 的 **AP 访客预约** / **AT 被访人审核** / **BD 主数据** 上增强协同与便捷：**G6 被访人邀约（邀请码 / 链接）** · **G7 被访人移动端审批** · **G8 常客快登** | V1.0（与 V1.1 **相互独立**，可并行也可择先） | 减少访客填单、**审批不必回电脑**、高频访客登记更快 |

> 边界骨架口径：上表列到「模块 + 增补能力（G 项）」粒度；每个模块内部的**具体功能点、字段、规则、状态迁移**一律留到该版阶段三滚动确定。
> G 项来源：阶段一已确认的 **G1–G11 全部纳入**（用户 2026-10-12）。**G4 随行人员逐人明细** 归入 **V1.0 AP 预约**（属预约表单基本项，非独立增强），故不单列版本；**G1/G11** 落 V1.0，其余 **G2/G3/G5/G9/G10** 落 V1.1、**G6/G7/G8** 落 V1.2。

## 二、逐版本推进顺序（阶段三 → 阶段四，每版一轮后独立封版）

| 顺序 | 版本 | 环节状态 | 轻量路径（§3.15） |
|------|------|---------|------------------|
| 1 | **V1.0** | 待开始（清单 / 审查 / 拍板 / 原型 / 交叉验证 / PRD 自查 / 封版） | 标准路径（首版，模块与需求量大） |
| 2 | **V1.1** | 待开始 | 待定（进入阶段三时判定：若「需求 ≤5 且纯增量」可走**轻量路径**，原型确认与封版确认合并为一张核对文档） |
| 3 | **V1.2** | 待开始 | 待定（同上） |

> 说明：**V1.1 与 V1.2 均只依赖 V1.0**，彼此无依赖；推进顺序 2/3 可互换（若要先把手机端审批体验做出来，可将 **V1.2 提前**）。默认按「先现场效率（V1.1）→ 再协同便捷（V1.2）」推进。

## 四、阶段二出口判定

- **判定标准**：全部规划版本（V1.0 / V1.1 / V1.2）的**序列与边界骨架已确认**；未决项已明确登记（Q8 排期未决——排期确定前不启动开发）。
- **确认方式**：项目负责人对「**版本序列 + 每版边界骨架**」回复 **无异议 / 报版本号+新口径 / 报版本号+否决原因**。
- **✅ 出口判定结论**：项目负责人于 **2026-10-12 13:45** 回复「**无异议**」——**V1.0 / V1.1 / V1.2 三版序列与每版边界骨架全部通过**。**阶段二出口判定 = 通过**，据此启动 **阶段三**（先做 **V1.0**）。
- **通过后**：进入 **阶段三**，对 **V1.0** 启动「详细需求清单 → 可测性审查门禁 → 拍板 → 高保真原型逐页确认 → US → TC → 交叉验证」闭环，收口后进入阶段四产出 **V1.0 PRD 并独立封版**；再依次推进 V1.1、V1.2。
