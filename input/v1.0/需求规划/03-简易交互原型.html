常客快登（G8）

**常客快登**：系统保存曾批准、无黑名单记录的访客信息，再次到访可**一键复用**快速登记；仍**须过黑名单预检与证件核验**方可放行。

申请入口二维码（后台生成）

张贴于校门 / 公示处
访客用手机**扫码** → 直接打开移动端访客端「我要申请」→ 填写并提交预约（**无需安装 App**）。
后台（管理员 / 门卫）可查看、下载、打印该二维码。扫码入口 = 访客进入访客端的两种方式之一（另一为门口门卫协助 / 现场登记）。

移动端审批（G7）

被访教职工可在**手机 H5** 上查看待办并同意 / 拒绝 / 改期（**消息推送直达**），无需回到电脑前处理——与桌面端同权、同一份待办聚合（见 PT「我的待办」）。

门卫核验放行 GV

现场核对身份 + 预约 / 凭证一致性、是否在有效时段；无预约走现场登记；进校 / 离校记时刻。

现场核验

证件识别（G2） / 现场人像采集（G3）

自动提取姓名、证件号并与预约比对；识别失败可**回退手工录入**（结果人工可改、留痕）。
核验时对访客**现场拍照留存**、绑定本次来访记录（用于事后追溯，非人脸比对）。

车牌识别 · 道闸联动（G10） / 访客证 · 临时通行卡（G9）

有车牌识别设备可联动道闸自动 / 手动放行；**无设备则门卫手工核对车牌**（校门设备开关可配，见 BD）。
核验通过后打印**访客证（贴纸）**或发放**临时通行卡**，供访客在校期间随身识别；**离校回收 / 作废**。

访客台账与查询 LG

个人信息保护（G11）

**个人信息保护（G11）**：访客姓名 / 证件号 / 车牌 / 人像等个人信息的**授权告知 + 最小必要收集 + 留存期限到期脱敏 / 清除**（期限可配，见模块地图 Q7）；访客可索取 / 更正本人信息（对应对象级隔离 §3.22）。
