## A 组 · 本版本做什么、不做什么（范围与目标）

> 这一组确认「V1.0 这个版本到底交付到哪一步」——后面所有条目都框在这条边界里。

| 编号 | 大白话释义（这一条在说什么） | 业务影响 / 谁受益 | 建议默认值 | 备选口径 |
|------|------------------------------|------------------|-----------|---------|
| A1 | V1.0 要把**核心闭环打通**：访客预约 → 老师审核 → 门口核验放行 → 进出登记 → 台账留痕 | 全流程跑通，这是最小可用版本 | 全线打通 | 可拆成两个小版本先做半条 |
| A2 | V1.0 还要一并交付**三项安全能力**：① 随行人员一个个登记（不再只填人数）② 在校实时清单（现在校内都有谁）③ 个人信息保护（留存到期脱敏） | 安全是系统的最终标尺 | 三项都进 V1.0 | 可后移到后续版本 |
| A3 | **不在 V1.0** 的：现场效率增强（证件识别 / 人像采集 / 超时催离 / 访客证 / 车牌道闸）→ 归 **V1.1**；协同便捷增强（被访人邀约 / 移动端审批 / 常客快登）→ 归 **V1.2** | 分批交付，V1.0 先保底 | 按此分批 | 可调整分批顺序 |
| A4 | V1.0 一共 **45 条需求，分 11 个能力域**（平台门户 / 预约 / 审核 / 门卫 / 访客手机端 / 台账 / 统计 / 权限 / 主数据 / 通知 / 系统管理） | 这是本版本的完整清单 | 45 条 | —— |

## B 组 · 四类人各管什么、能看到谁的数据

> 这一组是「保安全」的底线——直接关系到隐私和越权。**注意：这些限制会在服务器端强制**（不是只把按钮藏起来），越权访问一律拒绝并留痕。

| 编号 | 大白话释义 | 业务影响 / 谁受益 | 建议默认值 | 备选口径 |
|------|-----------|------------------|-----------|---------|
| B1 | **管理员**：维护账号、访客类型、黑名单、时段规则，看**全校**台账与统计 | 后台"总管家" | 全校可见可配 | —— |
| B2 | **门卫/保安**：只管**校门当日 / 现场**——核验、放行、进出登记、上报异常 | 一线值守 | 仅当日现场 | —— |
| B3 | **被访教职工**：**只能看与自己有关的**预约，处理同意/拒绝/改期（系统按本人身份强制过滤，看别人的一律拒绝） | 防"看到别人被谁访问" | **仅本人**（服务端强制） | —— |
| B4 | **访客本人**：**只有手机端（H5）**，**没有电脑端**，**只能看自己的**，只有「我要申请」「我的申请（查看）」两项 | 保护访客隐私 | **仅本人**＋**仅手机端** | —— |
| B5 | 管理员专属功能（用户管理 / 角色权限 / 主数据 / 系统设置）**其他人一律进不去**（越权返回"无权限"） | 权限边界清晰 | 严格 adminOnly | —— |
| B6 | V1.0 **没有**「代登录 / 身份模拟」能力——四类人都以真实身份登录 | 减少越权风险 | 不做 | 后续版本再评估 |

## O 组 · 一条预约的 8 种状态（请确认这套"进度"叫法）

> 门卫和老师看到的"进度条"就是这 8 个状态；每个状态"由谁/什么事件推动、什么时候生效"已在 PRD 写死。

| 编号 | 大白话：状态与怎么流转 | 建议默认值 |
|------|----------------------|-----------|
| O1 | 8 态：(1)**待审核** → (2)**已通过** / (3)**已拒绝** / (4)**已改期** / (5)**已过期** / (6)**已到访(在校中)** / (7)**已离校** / (8)**已取消**（**「已离校」＝可回退准终态**，D26） | 采用这 8 个 |
| O2 | 规律：提交→待审核；老师同意→已通过、拒绝→已拒绝、**改期＝提议改期→通知访客确认、确认后回「待审核」（D1/F-007a）**；**提议改期后超 3 小时未确认 → 定时任务自动转「已过期」（终态，D38）**；超过时段没来核验→**定时（每 10 分钟扫一次）**置已过期；门口核验→已到访(在校中)；登记离开→已离校；访客自己撤→已取消 | 采用 |
| O3 | 约束：**已到访不能取消/改期/拒绝**；已拒绝/已取消/已过期为**终态**；**「已改期」参与防重复未完结集、与是否终态解耦（D26）**；**「已离校」＝可回退的准终态**；**但"已离校"当天还能再进校（回到"在校中"）**；每次进出都留痕 | 采用 |
