**判定口径**：一条断言的“预期结果”无法由 PRD、原型可执行代码、DDD 模型任一权威源确定，且不能按权威顺序收敛为唯一值，即记为孤儿断言。孤儿断言不否定同一条 TC 的其余断言。

**本轮不执行测试**：孤儿判定是静态判定，不表示断言已在系统中运行失败。4 条孤儿断言在 `测试结果.md` 中统一记为“未执行”，执行结论为“不适用”。

### O-01 · TC-VS-002“令牌过期凭手机号+验证码重新换取”

| 项 | 内容 |
|----|------|
| 来源 TC | TC-VS-002 仅本人可见、越权 403 |
| 来源 US/REQ | US-VS-002 AC1；REQ-VS-002；D30 |

| 证据 | PRD REQ-NT-003；US-VS-002 AC1；`原型:1435-1436`；DDD `commands.json` 无换取令牌命令 |
| 处置 | 从可执行测试范围剔除；TC-VS-002 只执行核心断言。孤儿断言登记为规格缺口 G-01/G-02，RQ-02 已确认。 |
| 裁决关联 | `产品裁决结论.md` ADJ-035 |
| 人工确认 | RQ-02 已确认（2026-10-19）：V1.0 不提供令牌换发接口；令牌有效至预约终态；终态后访客重新扫码发起新预约。 |
