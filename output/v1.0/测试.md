## 一、判定规则

### 1.1 可验证的定义

一条 TC 可验证，当且仅当：其前置条件、操作步骤与预期结果可以由 `input/v1.0/` 内的 PRD、原型、DDD（含 REQ/US/06 等关联文件）确定地推出，且预期结果可以被单一观测判定为真或假。判定顺序：

1. PRD/REQ 明文有规定 → 直接采用。
2. PRD 未规定、原型可执行代码有确定行为 → 采用原型行为，并在结果中标注“原型依据”。
3. PRD 与原型均未规定、DDD 有确定模型 → 采用 DDD，并在结果中标注“DDD 依据”。
4. 三者均无确定口径，或彼此矛盾且无法按权威顺序收敛 → 该断言记为孤儿断言（O）。

### 1.2 判定级别

- **V（可验证）**：整条 TC 的预期结果可由权威源确定。
- **P（部分可验证）**：TC 的核心断言可验证，但含至少一条无权威口径的附加断言；核心部分进入本文件，孤儿断言进入《孤儿测试用例.md》。
- **O（不可验证）**：整条 TC 无任何可判定的预期结果。本轮为 **0 条**。

### 1.3 静态判定与执行状态

本轮不运行系统，`测试结果` 记录的是“规格可验证性”的静态判定，不是通过/失败。执行列统一为“未执行”。任何“通过”“失败”字样只出现在“预期结果”的表述中，不表示本轮已运行。

### 1.4 断言语义（全局）

- **拦**：请求不产生业务写入；HTTP **422**；响应体 `{code != 0, message, field}`；`field` 指向具体字段。
- **401**：未认证或账号停用/锁定。
- **403**：已认证但无权限；同时写一条 `action="越权拦截"` 的审计。
- **409**：状态冲突（重复审核、重复核销、已到访取消等）。
- **404**：资源不存在。
- **成功**：HTTP 200，响应体 `code = 0`，`data` 含业务对象。
- **“不落库”**：以同一查询条件再次请求，结果与操作前一致。
- **“留痕”**：审计表新增一条记录，字段满足 `user / time / objectType + objectId / action / result / before / after`。
- 所有时间判断使用服务端本地时区；测试通过可控时钟注入“当前时间”。

## 二、全局测试基线

### 2.1 角色与账号

| 代号 | 角色 | 登录方式 | 数据范围 |
|------|------|----------|----------|
| A1 | admin | 账号 `admin` + 密码 | 全校 |
| G1 | guard | 账号 `guard01` + 密码 | 当日/现场 |
| H1 | host | 工号 `T001` + 密码 | 本人相关（审核人归属） |

| V2 | visitor | 不可枚举会话令牌 | 本人绑定预约 |

密码基线：`abcdef`（6 位、无复杂度）为合法密码；`abc12`（5 位）为非法密码。

### 2.2 预约状态与集合

| 集合 | 成员 | 用途 |
|------|------|------|
| 终态 | 已拒绝、已过期、已取消 | 不可再流转；凭证失效 |
| 准终态 | 已离校 | 当天可回到“已到访(在校中)” |
| 未完结集 | 待审核、已改期、已通过、已到访(在校中) | 防重复判定的状态集合 |
| 到访成立集 | 已通过、已到访(在校中)、已离校 | 来访量统计的状态集合 |

状态中文名与英文枚举的对应：待审核=`pending`、已通过=`approved`、已拒绝=`rejected`、已改期=`rescheduled`、已过期=`expired`、已到访(在校中)=`on_campus`、已离校=`left`、已取消=`cancelled`。

### 2.3 时间与格式

| 项 | 唯一取值 |
|----|----------|
| 基准日 `D0` | 2026-10-12（周一） |
| 基准时刻 `T0` | 2026-10-12 09:00:00 |
| 可预约时段默认值 | 每天 07:00–18:00 |
| 有效时段缓冲（核验窗口） | 15 分钟，窗口端点含入 |
| 在校时长上限 | 240 分钟 |
| 到访/进校/离校展示 | `yyyy-MM-dd HH:mm` |
| 审计/通知/记录时间 | `yyyy-MM-dd HH:mm:ss` |
| 过期扫描 | 每 10 分钟一次；满足条件后的首次扫描内完成迁移 |

### 2.4 错误码

| 场景 | HTTP | 响应体 |
|------|------|--------|
| 未登录、账号停用、锁定中 | 401 | `{code, message}` |
